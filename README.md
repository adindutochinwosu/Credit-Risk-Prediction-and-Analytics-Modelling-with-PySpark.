# Credit-Risk-Prediction-and-Analytics-Modelling-with-PySpark.
This project focused on modeling customer credit risk using open-source data from an Indian financial institution to predict potential defaults on lending products. Among the machine learning algorithms tested, gradient boosting demonstrated superior performance compared to others, achieving an AUC value of 67%. To enhance predictive accuracy, further improvements are anticipated through parameter tuning using techniques like ParamGridBuilder and CrossValidator.
